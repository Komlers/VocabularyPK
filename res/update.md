# 本次 2.4 版本更新

本次更新带来本地数据管理、战绩导出、比赛中途终止、单人单列作答与整套渲染设置，词库补上必修 1 的 Welcome Unit，同时修掉一批影响判分与出题的问题。

## 一、本地数据管理（新增）

页面底部「数据管理」集中管本机的全部数据，只在本机读写、不联网：

- **导出备份**：勾选要带走的内容（班级名单 / 战绩与擂主 / 错词记录 / 词库与规则 / 个性化设置 / 自定义词库），导出成一个 `.json`。换电脑、换浏览器或清理浏览器数据之前，先导一份最稳。
- **导入备份**：选中备份后先显示摘要（几个班、几场战绩、几条错词），再选合并或覆盖。**合并**只补本机缺的部分（名单取并集、战绩按时间点去重、错词次数取较大值）；**覆盖**用文件里的同类数据整体替换本机。
- **按班级管理**：每个班的名单、战绩、擂主、错词与配置都能单独导出或单独删除。
- **分类清理**：只清某一类（全部战绩 / 错词记录 / 自定义词库 / 个性化设置），名单与其它记录保留。
- **不再静默丢数据**：浏览器本地空间写满时，页面会提示「⚠ 数据未能保存」并指向数据管理，而不是默默失败。

## 二、战绩窗口与导出

- **窗口重做**：顶部可切「全部 / 近 30 天 / 近 7 天」，列表上方的统计卡片跟着范围一起变。
- **导出 HTML**：可以导出当前范围、某一天或某一场，文件自带样式，双击就能看，也能直接打印或发到班级群。
- 战绩按班级隔离，清空也只清当前班级。

## 三、比赛中的控制

- **终止本局**：比赛进行中左上角出现「终止」（主界面的「安装」此时让位给它）。确认后本局立即作废——不计战绩、不收录错词、擂主不变，直接回主页。
- **确认框不再坑人**：弹出确认框时主倒计时、单题限时、换题延时一起暂停，点「继续比赛」从原来的剩余时间接着走。
- **自动全屏会自己退出**：点「开始 PK」时补的全屏，在终止比赛或结算后返回主页时自动退出；自己按的全屏不受影响。

## 四、单人作答与判分

- **单人改为一列**：只出一列淡紫色选项（限宽居中），一题只答一次，答错当场换题。
- **谁在作答一目了然**：「双人 / 单人」右侧用彩色粗体标出本局作答的人，例如「张三（红方）」。
- **修复**：双人局里一方连击后，被对方先答对时本方连击没有中断，下一题仍在叠加。
- **修复**：错词加时赛不再把班级限时改成 30 秒，回到主页后限时按钮与实际时长仍对得上。
- **修复**：换词库后的「错词优先复现」只插当前词库范围内的错词，不再被别的册的旧错词占掉开场几题。

## 五、渲染设置（新面板）

从「擂台设置」拆出「渲染设置」，只管本机显示与反馈，改动即保存：

- **渲染动画三档**：完全（页面、弹窗、切题都有过渡）/ 部分（只留飘字与答对答错等小动效）/ 禁用（最省性能）。
- **全局字体**：微软雅黑 / 苹方 / 思源黑体 / 小米 MiSans / 鸿蒙黑体任选，选完立刻生效。新用户按操作系统自动挑一款（Windows 雅黑、macOS 苹方、鸿蒙鸿蒙黑体、其它思源黑体）；本机没装的字体会自动回退。
- **三个开关**：计分飘字（+N / -N / ⏰）、答题音效、自动朗读单词。
- 系统开启「减少动态效果」时，动画自动按禁用处理。

## 六、主页与文案

- 主页四步重排：「出题范围与时长」与「对局规则与设置」拆成两张卡片，「已选词库」下方加了名称预览（最多 5 个）。
- 「临时赛」由复选框改成胶囊开关，「双人 / 单人」改成分段控件，两项都随改随存。
- 全站文案统一精简：说明不再与标签重复，动画三档各自说清，词块重组提示按实际的干扰片段数显示。

## 七、词库与出题

- **新增必修 1 Welcome Unit**：内置词库 35 → **36 个**。
- **词块重组题真的会出现了**：原来几乎抽不到，现在按比例正常分配到每局。
- 跨单元出现的同一个单词，词条全部保留，复现时取当前词库那一条，释义不会串册。
- 自定义词库导入会逐条校验（缺中文、用了数字等条目会被跳过并提示条数）；删掉正在使用的自定义词库，不再导致下一局开局崩溃。
- 题池为空、错词无法复现、坏数据等情况都有提示，不再白屏或空开一局。

## 八、名单编辑器

- **唯一的名单入口**：TXT 导入也收进编辑器，主页不再单设导入按钮。
- 一个班都还没有时，点「📥 导入」会先请你起个班级名并在导入时自动建班，不再要求先回主页导入。

## 九、无障碍、文档与稳定性

- **键盘可用**：14 个内容弹窗补上对话框语义与可读标题；打开时焦点进入弹窗、关闭时还给原来的按钮；`Esc` 关最上层，`Tab` 在弹窗内循环，不再一次关掉两层。
- **文档弹窗不再干等**：更新说明、使用说明、名单帮助、词库帮助点击即弹窗，正文位置先显示「正在加载…」，取到后再换成内容；失败就在原位给出原因和「重试」。
- **关于项目**：正文移到 `res/about.md`，与其它文档同一套排版，改文案不用再动页面结构。
- **文档拆分**：README 只留基础介绍与玩法，出题算法、存储结构、部署等深入内容移到 `res/intro.md`。
- **子路径部署**：站点挂在子目录时，404 页面会按当前站点根路径去找样式与图标。
