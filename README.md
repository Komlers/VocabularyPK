# 词汇擂台 PK

面向高中英语课堂的**双人单词对战网页**：红方擂主 vs 蓝方挑战者，同屏限时答题，败者守擂实现车轮战。纯前端，无需注册、无需后端，浏览器打开即用。

**在线使用：[pk.danevan.top](https://pk.danevan.top/)**（建议用 Edge / Chrome，可「安装」成桌面应用）

---

## 功能一览

**对战**
- 双人同屏 PK / 单人练习两种形态，随时切换
- 30 秒 ～ 5 分钟限时，倒计时结束自动结算
- 三种计分模式（无限制 / 淘汰制 / 累加制），连击加分与答错扣分可调
- 每题超时检测（3s / 5s / 7s），超时跳过、双方不计分
- 中途可「终止」本局，按临时赛处理；确认弹窗开着时计时暂停

**出题**
- 36 个内置词库（人教版必修 1～3、选择性必修 1～4），可多选混合
- 单词题 + 词块三题型（选义 / 配对 / 重组）
- 错词优先复现：下一局开头先考本班错词（限当前词库，最多 8 个）
- 支持导入自定义 JSON 词库

**记录**
- 战绩按班级、按日期分组，可切「全部 / 近 30 天 / 近 7 天」
- 错词记录按册 / 单元累计，标出每词累计出错次数
- 战绩、错词、结算结果都能导出成自带样式的 HTML
- 整份数据（名单 / 战绩 / 错词 / 配置 / 自定义词库）可导出 JSON 备份，换机导入

**显示与体验**
- 开始 PK 自动全屏；由代码补的全屏会在结束后自动退出
- 渲染设置：全局字体、动画三档（完全 / 部分 / 禁用）、计分飘字、音效、单词朗读
- 所有提示都在网页内弹窗完成；支持 Esc 关闭弹窗、Tab 在弹窗内循环
- 大屏适配（4K / 300% 缩放）、可安装为桌面应用、断网也能打开

## 三步上手

1. **准备名单**：点「✏️ 名单编辑器」→「➕ 新建班级」→「📥 导入」选一个 TXT（一行一个名字）；增删改也都在这个编辑器里。
2. **上台选手**：点红方 / 蓝方框随机抽取，或点「输入」手打；想一个人练就把「双人 / 单人」切到「单人」。
3. **开战**：选词库与限时，点「开始 PK」。时间到自动出结算页。

还没有名单也能玩：直接在「上台选手」里输入两个名字即可开打，这局属于**临时体验，不记录战绩**。

## 玩法说明

### 双人与单人

- **双人**：左右各一套选项，同时作答、互不干扰；一侧答错只锁住自己那一列。
- **单人**：只有一列淡紫色选项（限宽居中），一题只答一次，答错直接换下一题。
- 模式开关右边会用彩色文字标出本局由谁作答。

### 计分

| 模式 | 初始分 | 答对 | 答错 | 结束 |
|---|---|---|---|---|
| 无限制（默认） | 0 | 10 分起，连击递增到 30 | 默认不扣，可开启连错扣分 | 时间到比总分 |
| 淘汰制 | 满分（50/100/150） | +5，不超过满分 | -10，不低于 0 | 一方归零即输 |
| 累加制 | 0 | +5，不超过满分 | -10，不低于 0 | 一方先到满分即赢 |

- **连击**：自己答错、被对方先答对同一题、整题超时都会中断连击。
- **加时赛**：结算页可发起 30 秒错词复盘，答对 +5、不扣分、不参与胜负判定，也不入账。

> 完整的加减分细节、连击公式与平局判定见 [深入说明](res/intro.md#五计分与结算)。

### 败者守擂与战绩

- 每局结束败者成为下一局擂主（红方），回主页时已回填，选好挑战者即可再战。
- 平局按连击纪录判定：连击低者守擂；连击相同则换人；双方全对则清空擂主。
- 主页「📊 历史战绩」按日期列出比分、结果、计分模式、词库与题量，可按范围或单场导出 HTML。

### 错词记录与复现

- **错词记录**：按班级累计每场正常对局答错的单词与词块，答对也不清零，适合看整学期的顽固错词；可导出 HTML。
- **错词优先复现**：开启后，下一局开头先考本班累计错词（按错误次数取前 8 个，且只取当前所选词库范围内的），答对即出本。
- 临时赛与加时赛不收录错词。

### 临时赛与终止

- 主页第 4 段点亮「临时赛」：本局战绩、错词记录、擂主都不写入。
- 比赛中左上角出现「终止」，确认后本局立即作废并回主页；确认框开着时计时暂停。

### 快捷键

| 按键 | 功能 |
|---|---|
| `F` | 进入 / 退出全屏 |
| `Esc` | 关闭最上层弹窗；没有弹窗时退出全屏 |
| `Tab` / `Shift + Tab` | 在弹窗内循环切换焦点 |

## 词库

内置 **36 个词库**，覆盖人教版高中英语必修 1～3（含必修 1 的 Welcome Unit）与选择性必修 1～4，共 7 册。

- 词库弹窗里按册分组，默认收起；每册和「全部单元」都能一键全选 / 清空。
- 多选时题池包含所有选中词库的词条，单词题与词块题按比例穿插。
- 也可以导入本地 JSON 自定义词库：[制作方法](res/custom.md)。

> 各册单元清单与词库数据格式见 [深入说明](res/intro.md#六词库数据)。

## 安装与运行

**安装为桌面应用**：用 Edge / Chrome 打开，点左上角「安装」（只在主界面显示；比赛中让位给「终止」）。装好后从开始菜单打开，独立窗口、断网可用。

**本地运行**：`file://` 下浏览器禁止读取本地 JSON，需要起一个 HTTP 服务：

```bash
python -m http.server 8080     # 然后打开 http://localhost:8080
```

**自部署**：纯静态、无需构建，可直接托管到 Cloudflare Pages / Vercel / GitHub Pages，输出目录填根目录即可。缓存与 Service Worker 的注意事项见 [深入说明](res/intro.md#八部署与缓存)。

## 数据与隐私

- 所有数据（名单、战绩、擂主、错词、配置、自定义词库）只存在**本机浏览器的 localStorage**，不上传任何服务器。
- 无账号、无追踪、无广告。
- 清除浏览器数据会丢失记录，建议先用页面底部的「数据管理」导出一份 `.json` 备份。
- 浏览器本地空间写满时会弹「⚠ 数据未能保存」，此时先导出备份，再清理旧战绩或错词。
